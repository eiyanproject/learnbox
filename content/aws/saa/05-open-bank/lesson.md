These questions come from **aws-saa-tips** by **Berkay Cakibey**
(github.com/BerkayCakibey/aws-saa-tips, commit 0c2d2e8), published under the
MIT licence. Its author describes them as original, unofficial practice
questions written with AI assistance and reviewed by hand, not taken from
the exam or from other question banks. Each one cites AWS documentation,
shown under the explanation here.

The questions and explanations are unchanged. Only the order of the answer
options is different (shuffled so the right answer is not always the same
letter), and each question's "key rule" has been appended to its
explanation. The number in each reference (Q001 to Q325) and its topic match
the original bank.

They are grouped by topic (networking, security, databases, migration and
so on) rather than by the four exam domains, so they have their own mock
exam: **Solutions Architect - Associate (SAA-C03): open bank**, 65 questions
drawn at random from the 325. The domain-weighted SAA mock exam still uses
only the questions in topics 1 to 4.

Like any practice bank, it may contain mistakes. If an answer looks wrong,
check it against the linked documentation.
